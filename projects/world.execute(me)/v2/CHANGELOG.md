# 更新日志（v2）

## v2.0.0 — 2026-10-05

「SOURCE」：推倒重来的第二版。不再做字符画——**整部 MV 是一个代码编辑器里
的一份 `me.rs`**，全程用 Rust 源码本身演绎歌词：歌词是注释，剧情是编码，
报错是命运，drop 是死亡。

- **时间轴与 v1 完全一致**（19 幕、同一套离线频谱对位），音频 / 画布 / 终端 /
  歌词解析四大基础设施沿用 v1 成熟实现；v2 自包含成独立 cargo 项目，
  素材复用作品根目录 `assets/`。
- **新增 `code.rs` 源码文档引擎**：
  - 自写 mini Rust 语法高亮器（关键字 / 类型 / 函数 / 宏 / 字符串 / 属性 /
    生命周期 / 注释，One Dark 风格调色）
  - `DocBuilder` 声明式排布"哪一行、什么时刻开始打字"，自动行号与光标归属
  - 行模型支持：打字 reveal、光标闪烁、diff 装订线（`+`/`-`/未保存点）、
    整行底色、错误区间、查找高亮、补全幽灵文本、折叠标记、注释关键词芯片
  - 全部使用舞台相对坐标，可嵌任意子视口（LoveTrapped 分屏 diff 即由此实现）
- **编辑器部件**：rustc 诊断框（error[E0xxx] + `-->` + `^^^^` 指示，逐列打字）、
  单行悬停卡、查找替换条、全宽注释横幅。
- **编辑器外壳（chrome 重写）**：标签页栏（me.rs 未保存圆点 / 终局关闭）、
  歌词条改为注释形态（`//` + 关键词芯片，中文行 `//!`）、IDE 状态栏
  （E/W 诊断计数随剧情演化、Ln/Col、braille 转圈的 rust-analyzer 状态、
  播放位置），隐藏叙事 `user@localhost` 掉线原样保留。
- **新特效模块 `fx2.rs`**：代码 token 雨（不压代码本体）、行涟漪冲击波、
  braille 转圈、文本仪表。
- **19 幕全部重写为"编码现场"**：打字开机、大字 `world.execute(me);` 逐字
  点亮、match 臂悬停卡、查找替换 AC→DC 与 F→M/S→M、满足度仪表、
  borrow checker 困笼（花括号合拢 + E0499）、diff 长出蔬菜 impl、
  `type Proof = You;` 金色点亮、trance 折叠催眠、六次 "you have left"
  逐行 diff 删除、退格风暴、E0004 非法参数、PROBLEMS 面板宣判 +
  EXECUTE 落章、12 连 `execute!(me);` 红章弹幕 + 六国计数彩色注释、
  cargo build 失败、`fn love` 类型推导解出 `Heart`、
  `move into 'love'` 分屏（you 自由 / me 被困）、文件清空 + 最后一行
  `//! （你还在。它没有了。）`。
- 每幕以"前文折叠标记 + 压暗上下文行"开场，营造同一个文件在生长的连续感。
- 全局后处理沿用 v1（辉光 / 扫描线 / 渐晕 / 故障 / 孤独褪色，窗口相同）。
